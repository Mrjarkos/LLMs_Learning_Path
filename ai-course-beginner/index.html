Run order on the day

  1. Open Slides and present segments 1–3 (mental model + core skill).
  2. Drive the Live demo from the runbook on the sample repo.
  3. Hand out the Exercise sheet; attendees do the hands-on.
  4. Return to slides for “how it’s built” + takeaways.
